# 现场演示固定脚本（答辩用，逐条打勾执行）

## 演示前 5 分钟（一次性）
- [ ] 启动 RPA mock：`python <数据包>/05_RPA接口文档/mock_rpa_server.py`
- [ ] 预热缓存：`python scripts/demo_cache.py`（3 场景秒开）
- [ ] 预热 RPA 任务：`python -c "from app.rpa.warmup import warmup; print(warmup())"`
- [ ] 启动前端：`streamlit run frontend/app.py`

## 演示顺序（固定，不临时发挥）
1. **报告生成**（缓存秒开）→ 下载报告 → 口播"零残留 + 数字溯源"
2. **看板** → 四图各停 5 秒 → 口播"分层校准：旧0条 vs 新3条"
3. **对标审计** → 滚到检验器红黄蓝灰绿 → 口播"红4黄2蓝1灰1绿4"
4. **What-if**（现场拖滑块）→ 口播"Σ增量=总变动恒等式"
5. **因果引擎**（六味 3 月）→ 口播反事实 + "无足迹诚实标注"
6. **RPA** → 确认推送 → 状态追踪 → 口播"human-in-the-loop"

## 兜底（任一环节卡住）
- 报告缓存秒开失效 → `python scripts/demo_cache.py` 现场重跑（<10s）
- LLM API 不可用 → 系统自动 MockLLM（离线模式，页面上如实标注）
- mock 服务未起 → RPA 页显示"服务未启动"红色提示 + 上一轮成功快照（不白屏）
- 任何数字被质疑 → 打开 evidence/phase3_validate.log 或现场跑 `python scripts/run_checks.py`（30 秒出 88 项金丝雀）
